# Asset provenance

All 15 equipment illustrations in `web/public/images/*.svg` are original vector
still lifes authored for this repository in `scripts/generate-art.mjs`.
Creator: Ammaar's Fieldroom project, with Codex assistance. Source: the generator
in this repository; license: [MIT](../LICENSE). No third-party artwork, tracing,
logos, photographs or models are incorporated. Product names/specifications are
fictional. Illustrations are interpretations, not photographs of real inventory.
Regenerate with `node scripts/generate-art.mjs`.

Font stacks use installed system fonts (Georgia, Arial, Courier New with generic
fallbacks). No font files are redistributed or downloaded. No GLB, WebGL, external
images or remotely hosted assets. UI screenshots are generated from this local
application with fictional records only and contain no credentials.
